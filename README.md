# Red Team – Centro de aprendizaje

Centro de aprendizaje de red team con Kali Linux: temas, ejemplos y ejercicios, en español.

## Ver el centro

El centro interactivo está en `index.html`. Actívalo con GitHub Pages (Settings → Pages → Deploy from a branch → `main`) y accede en:

**https://securityverse.github.io/red-team-centro-de-aprendizaje/**

## Contenido

- 6 fases: Fundamentos, Reconocimiento y escaneo, Enumeración y explotación, Post-explotación y pivoting, Active Directory, Evasión/C2 y reporte.
- Ejemplos de comandos copiables, ejercicios con soluciones, quiz interactivo, glosario buscable y diario de lab descargable.

> Todo el material es para práctica en laboratorio propio.
